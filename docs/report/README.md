# Summary report

[`scientific-qa-evidence-report-v1.2.0.pdf`](scientific-qa-evidence-report-v1.2.0.pdf) is a five-page summary of the study at release v1.2.0 plus the Clay–Lean bridge plan (commit `c400a6b`): conclusions, formal results, the numerical campaign, the findings, the blind-fault benchmark with its review rounds, and the semantic work plan. Every number in it comes from records in this repository.

It is generated from [`report.html`](report.html) with Chromium (Playwright `page.pdf`, A4). The SHA-256 of both files is listed in `evidence/SHA256SUMS.txt`. The repository, not the PDF, is the authoritative record.
