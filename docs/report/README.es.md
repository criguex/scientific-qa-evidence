# Informe resumen

[`scientific-qa-evidence-report-v1.3.1.pdf`](scientific-qa-evidence-report-v1.3.1.pdf) resume el estudio en la versión v1.3.1 en siete páginas: conclusiones, resultados formales en cinco compilaciones, la campaña numérica, los hallazgos, el benchmark de fallos a ciegas, los puentes en Lean del teorema de OpenAI al texto de Clay, los controles con Mathlib, la comprobación de recibos sobre registros auténticos, y cómo se reproduce todo. Cada número en él viene de registros de este repositorio. Los informes anteriores se conservan sin cambios, para el registro: [v1.3.0](scientific-qa-evidence-report-v1.3.0.pdf), [v1.2.0](scientific-qa-evidence-report-v1.2.0.pdf).

Se genera a partir de [`report.html`](report.html) con Chromium (Playwright `page.pdf`, A4). El SHA-256 de cada archivo está listado en `evidence/SHA256SUMS.txt`. El repositorio, no el PDF, es el registro autoritativo.
